# 🏓 NEON PONG — как выложить игру в интернет

Понг для двоих по ссылке: создаёшь игру → кидаешь ссылку другу → играете в реальном времени.
Здесь — инструкция, как получить **постоянную бесплатную ссылку** вида `https://neon-pong-xxxx.onrender.com`.

⏱ Займёт ~10–15 минут. 💳 Банковская карта не нужна.

Понадобятся два аккаунта: **GitHub** (хранилище кода) и **Render** (хостинг, который запускает код).
Render умеет забирать код прямо из GitHub и сам всё собирать — это самый простой путь.

---

## Шаг 1. Загрузить код на GitHub (3 минуты)

1. Зайди на [github.com](https://github.com) → зарегистрируйся или войди.
2. В правом верхнем углу нажми **«+» → «New repository»**.
3. Заполни:
   - **Repository name**: `neon-pong`
   - **Public** (публичный — Render бесплатно работает с публичными репозиториями)
   - Галочки «Add a README» и прочие — **не ставь** (репозиторий должен быть пустым).
4. Нажми **«Create repository»**.
5. На открывшейся странице найди ссылку **«uploading an existing file»** (в тексте-подсказке) и нажми её.
6. Распакуй архив `pong-deploy.zip` на компьютере и **перетащи все файлы и папки** в окно браузера:
   - `package.json`, `package-lock.json`
   - `server.js`
   - папку `public/` (внутри `index.html`)
   - `render.yaml`, `Dockerfile`, `.gitignore`, `.node-version`, `README.md`
   - ⚠️ Папку `node_modules` перетаскивать **не нужно** — хостинг сам установит зависимости.
7. Внизу нажми зелёную кнопку **«Commit changes»**.

Готово — код на GitHub. ✅

## Шаг 2. Подключить Render (5 минут)

1. Зайди на [render.com](https://render.com) → **«Get Started»** / **«Sign in»**.
2. Выбери вход **через GitHub** («Sign in with GitHub») — так Render сразу увидит твой репозиторий. Разреши доступ.
3. В панели (Dashboard) нажми **«New +» → «Web Service»**.
4. В списке репозиториев найди `neon-pong` → **«Connect»**.
   - Если репозитория нет в списке: нажми «Configure account» / «Connect account» и дай доступ к репозиторию `neon-pong`.
5. Заполни настройки:
   - **Name**: `neon-pong` (или любое — оно попадёт в адрес ссылки)
   - **Region**: выбери ближайший к тебе и другу (например, *Singapore* или *Frankfurt*)
   - **Branch**: `main`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: **Free** 💸
6. (Необязательно) В «Advanced» → **Health Check Path**: `/health`
7. Нажми **«Create Web Service»**.

## Шаг 3. Дождаться и играть 🎮

1. Render начнёт сборку — внизу побегут логи. Через 2–4 минуты появится зелёная надпись **«Live»**.
2. Вверху страницы будет твоя ссылка: **`https://neon-pong-xxxx.onrender.com`** — это она, постоянная!
3. Открой её → **«🎮 Создать игру»** → **«🔗 Копировать»** → кидай другу ссылку на комнату.
4. Друг открывает ссылку — и вы играете. Первый до 7 очков. 🏆

---

## ⚠️ Что важно знать про бесплатный тариф

- **Сервер засыпает после 15 минут без посетителей.** Первый заход после паузы занимает ~30–60 секунд (сервер просыпается) — это нормально, просто подожди. Дальше всё летает.
- **Во время игры сервер не заснёт**: WebSocket-сообщения считаются активностью, так что матч не прервётся.
- Если ссылка «спит», а друг нетерпеливый — открой её сам за минуту до игры. 😉
- Хочешь, чтобы сервер никогда не засыпал — у Render есть платный тариф (~$7/мес), включается в настройках сервиса в любой момент.

## 🔄 Как обновлять игру

Меняешь файлы в репозитории GitHub (через веб-интерфейс: файл → карандаш ✏️ → Commit) — Render **автоматически пересоберёт и обновит** игру через пару минут. Ничего нажимать не надо.

## 🛠 Запуск на своём компьютере (для проверки)

```bash
npm install
npm start
# открой http://localhost:3000
```

Нужен Node.js 18+ ([nodejs.org](https://nodejs.org)).

## 📦 Что внутри

| Файл | Зачем |
|---|---|
| `server.js` | Сервер: комнаты, физика 60 к/сек, рассылка состояния через WebSocket |
| `public/index.html` | Вся игра: неоновый canvas, управление, звуки (один файл, без зависимостей) |
| `package.json` | Зависимости (`ws`) и команда запуска |
| `render.yaml` | Blueprint для Render (настройки деплоя) |
| `Dockerfile` | Универсальный образ — подойдёт для Railway, Fly.io, VPS |
| `test.js` | Автотест: два бота играют партию (`npm test` при запущенном сервере) |

Удачи! Если на каком-то шаге застрял — опиши, что видишь на экране, и я помогу. 🚀
